# Career Intelligence — Unified Multi-Role Frontend

Unified prototype combining the Student and Employer portals.

## Roles
- Student
- Employer
- University / Career Adviser

Registration stores the selected role in localStorage for prototype testing and redirects to the corresponding portal. This is intentionally a frontend prototype; replace the localStorage authentication with the FastAPI authentication API when the backend is connected.

## Run
```bash
npm install
npm run dev
```
