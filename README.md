🌟 01. Project Overview
Career Intelligence Platform is a modern, intelligent and inclusive digital ecosystem designed to bridge the gap between education, professional skills and employment opportunities.

The platform brings together students, employers and universities in one connected environment, using intelligent analysis, career recommendations, skill-gap identification and employment matching to improve career development and recruitment.

Rather than simply helping users search for jobs, Career Intelligence focuses on understanding individual capabilities, identifying professional opportunities and guiding users towards meaningful career growth.

💡 Our Mission
To transform how individuals discover careers, develop professional skills and connect with employment opportunities through intelligent technology and data-driven insights.

🎯 02. Core Objectives
🎓 Empower students to discover suitable career paths.

🚀 07. Installation & Setup
Get the platform running on your local development environment.

📋 Prerequisites
Before installation, ensure you have:

🐍 Python 3.10+
🟢 Node.js and npm
🐬 MariaDB Server
🌿 Git
💻 Visual Studio Code or another suitable IDE
1️⃣ Clone the Repository

bash
git clone https://github.com/ojijotom/FINAL-CAREER-INTELLIGENCE.git

bash
cd FINAL-CAREER-INTELLIGENCE
2️⃣ Configure the Backend

bash
cd careerintelligence-backend
Create a virtual environment:


bash
python -m venv venv
Activate it on Windows:


bash
venv\Scripts\activate
Install dependencies:


bash
pip install -r requirements.txt
Run database migrations:


bash
python manage.py migrate
Start the backend:


bash
python manage.py runserver
3️⃣ Configure the Frontend
Open another terminal:


bash
cd careerintelligence-frontend
Install dependencies:


bash
npm install
Start the development server:


bash
npm run dev
4️⃣ Database Setup
Create the MariaDB database:


sql
CREATE DATABASE career_intelligence;
Configure your database credentials using the backend's environment configuration.

🔐 Security Reminder: Never upload database passwords, API keys or secret credentials to GitHub.
Note: Follow the actual project configuration files for dependency versions, environment variables and database settings.
